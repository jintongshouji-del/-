
# 🚀 QuickStore AI - 轻量化电商管理系统

这是一个基于 React + Tailwind CSS 开发的极简电商引流工具。

## ✨ 功能特点
- **产品展示**：优雅的卡片布局，展示价格与属性。
- **购物车系统**：完整的选购流程，支持数量增减。
- **线索采集**：下单自动采集姓名、电话、微信号。
- **管理后台**：
  - 产品上架/下架。
  - 订单实时查看与管理。
  - **一键复制**：快速提取客户订单信息，方便微信沟通。

## 🛠️ 如何在本地运行

1. 克隆仓库：
   ```bash
   git clone https://github.com/您的用户名/my-quick-store.git
   ```
2. 安装依赖：
   ```bash
   npm install
   ```
3. 启动开发服务器：
   ```bash
   npm run dev
   ```

## 🌐 部署说明

建议使用 **Vercel** 进行部署：
1. 关联 GitHub 账号。
2. 导入本项目。
3. 构建设置保持默认即可。
