
# 🎆 全球花炮集合 - 专业烟花订购系统
### Author: binbinaidapao

这是一个专注于烟花、爆竹行业的轻量化电商引流及订单管理系统。

## ✨ 功能特点
- **花炮展示**：精美的卡片布局展示各种烟花效果图、价格与规格。
- **预订清单**：完整的选购流程，支持数量增减及总额计算。
- **线索采集**：下单自动采集姓名、电话、微信号，方便后续沟通配送。
- **管理后台**：
  - **新品上架**：支持电脑端上传图片或手机端直接拍摄上架。
  - **订单管理**：自动记录下单时间、金额，支持标记处理状态。
  - **一键复制**：快速提取客户需求信息。

## 🛠️ 技术栈
- React 19
- Tailwind CSS
- LocalStorage 持久化存储
